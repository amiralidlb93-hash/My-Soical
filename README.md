# Developer Links

A small responsive link page for my developer profiles.

## Included links
- YouTube channel
- GitHub profile

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the root of your repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`, then save.

The page intentionally has no website/social website section. Update the links in `index.html` if your profile URLs change.
